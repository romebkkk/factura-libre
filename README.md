# 🧾 Factura Libre

> Free invoices for Spanish freelancers: VAT, IRPF withholding, NIF validation, auto-numbering and print/PDF. No signup, data stays in your browser.

**Free · open source · 100% in your browser (nothing is uploaded).**

<sub>[🇪🇸 Español abajo](#-español)</sub>

## Features
- Mandatory fields per RD 1619/2012
- NIF/NIE checksum

## Use
Open `index.html` — no install, no server, no build. Host it free on GitHub Pages.

## Basis
RD 1619/2012 (Reglamento de facturación).

## ⚠️ Disclaimer
Orientative tool — not legal, tax or financial advice. Check your specific case with a professional.
